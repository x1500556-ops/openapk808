# Vik808 plugins

Plugins are small Python modules **generated by the brain (GPT)** from a description,
each paired with a `SKILL.md` so the skills engine can drive it.

## Create one

- Telegram: `/genplugin a tool that converts OpenAPK table rows into a CSV`
- CLI: `python main.py genplugin "a tool that converts OpenAPK table rows into a CSV"`

## Layout

```
plugins/<name>/
├── PLUGIN.json     # name + summary
└── *.py            # generated modules (stdlib only)
skills/<name>/
└── SKILL.md        # registered alongside the plugin
```

Generated code must be stdlib-only and must not perform network calls at import time.
Review generated plugins before running them in production — same as any AI-written code.
